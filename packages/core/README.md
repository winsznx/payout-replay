# @payout-replay/core

The engine behind [Payout Replay](https://github.com/winsznx/payout-replay): strict CSV import, canonical manifests with a SHA-256 digest, keccak obligation IDs, reconciliation and fail-closed recovery planning. No chain access; pure TypeScript.

Most apps want [`@payout-replay/sdk`](https://www.npmjs.com/package/@payout-replay/sdk), which re-exports this package. MIT licensed.
